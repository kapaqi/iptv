# iptv player
iptv 播放器, 直播源
支持Android系统(手机,平板,TV)
支持Macos系统(Apple arm64/Intel x86_64)


可以设置自定义m3u菜单适配自己的节目单

可以设置udproxy地址来适应组播转单播的iptv环境
